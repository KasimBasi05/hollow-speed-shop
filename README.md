# Hollow Cars

Build a simple, clean, fast front-end-only Hot Wheels-inspired car shop called “Hollow Cars.” Include Home with a hero banner, title and Shop Now CTA; Products with a responsive grid of car cards (image, name, price, Add to Cart); and Cart with added items, totals, and Checkout button. Use bold sporty typography and a red, black, white palette. Make it mobile friendly. No backend.

This project was built with [Lovable](https://lovable.dev).
